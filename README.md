# 《密阵突围》- Matrix Breakout

## 项目简介

《密阵突围》是一款基于江苏卫视《最强大脑》第13季经典挑战项目开发的策略益智游戏。玩家需要在由字母（A-E）和数字（0-9）组成的代码矩阵中，选择若干个"操纵代码"，通过上下左右移动实现代码合并，最终完成突围。

本项目使用 C++17 开发，运行于 Windows 控制台环境，完整还原了原版节目的核心玩法，并扩展了题库管理、成绩排行榜、对局回放等实用功能。

---

## 游戏玩法

### 核心规则

1. **盘面大小**：由难度系数 `a` 决定，盘面为 `5a × 5a` 的网格
2. **操纵代码**：玩家需要选择 `a` 个格子作为初始操纵代码
3. **移动方式**：使用 `W/A/S/D` 控制所有操纵代码同时向同一方向移动
4. **合并规则**：
   - 字母相同：数字相加取个位，字母不变（如 `A3 + A5 = A8`）
   - 数字相同：字母按五进制加法（A=1,B=2,C=3,D=4,E=5），数字不变（如 `A3 + C3 = D3`）
   - 完全相同：保持不变
   - 其他情况：移动失败
5. **游戏结束**：当所有操纵代码都无法移动或合并时，游戏结束
6. **得分**：每次成功合并得 1 分

### 合并规则示例

| 操作前 | 操作后 | 规则 |
|--------|--------|------|
| A3 + A5 | A8 | 字母相同，数字相加取个位 |
| A3 + C3 | D3 | 数字相同，字母相加（A=1,C=3→4→D） |
| A3 + A3 | A3 | 完全相同，保持不变 |

## 功能特性

### 已实现功能

- ✅ 核心游戏逻辑（盘面初始化、联动移动、合并判定）
- ✅ 难度选择（a = 1~10，盘面大小 5×5 至 50×50）
- ✅ 随机盘面生成

## 运行说明

### 环境要求

- 操作系统：Windows 10 / 11
- 编译器：Visual Studio 2022（或支持 C++17 的编译器）
- 依赖库：标准库 only，无需额外安装

### 编译运行

1. 使用 Visual Studio 2022 打开 `Project1.vcxproj`
2. 设置解决方案配置为 `Debug x64` 或 `Release x64`
3. 按 `F5` 或 `Ctrl + F5` 运行程序

### 控制台编码设置

程序会自动将控制台代码页切换为 UTF-8（65001），确保中文字符正常显示。如遇乱码，请确保系统控制台支持 UTF-8 编码。

## 操作指南

### 主菜单

```
1. 开始新游戏（随机盘面）
2. 选择题库题目
3. 查看排行榜
```

### 游戏内操作

| 按键 | 功能 |
|------|------|
| W / w | 向上移动 |
| S / s | 向下移动 |
| A / a | 向左移动 |
| D / d | 向右移动 |
| Q / q | 退出游戏 |

### 初始操纵代码选择

- 输入格式：`行号 列号`（如 `0 1`）
- 需要选择恰好 `a` 个非空格子作为操纵代码
- 操纵代码在盘面中显示为绿色（如 `*A1*`）

## 得分计算

**得分率 = 合并次数 / 总操作次数**

得分率越高，说明玩家的操作效率越高。排行榜按得分率从高到低排序。

## 常见问题

### Q1：控制台中文显示乱码？

**A**：程序已自动设置 UTF-8 编码。如仍有乱码，请在运行前执行 `chcp 65001` 或使用 Windows Terminal。

### Q2：自定义题目保存后找不到？

**A**：检查 `data/questions.txt` 文件是否存在，以及文件编码是否为 UTF-8。

### Q3：回放列表为空？

**A**：需要先完成一局游戏，回放记录会自动保存。游戏结束后才能查看回放。

### Q4：游戏卡顿或绘制慢？

**A**：盘面较大时（如 a=10，50×50 盘面）绘制会稍慢，属正常现象。建议使用 Release 模式编译以获得更好性能。
